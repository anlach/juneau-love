# user-story

* [Access by approval status](access-by-approval-status.md) - A signed-in user's screen is determined by their approval state — pending sees an awaiting screen, rejected sees a rejection screen, approved sees guest content (admins additionally the registrations page).
* [Register as a guest](register-as-guest.md) - A guest registers with email, display name, and password; the registration starts in pending state and waits for an admin decision.
* [Review registrations (admin)](review-registrations.md) - The admin opens a registrations page listing every registration with its approval state, and can approve or reject each one.
